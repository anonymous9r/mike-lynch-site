# Mike Lynch — Portfolio & Résumé

Proof-led portfolio for SEO, e-commerce growth, and AI-systems roles. Plain HTML/CSS/JS, deployed on Netlify from `main`.

## Structure
- `index.html` — hero + role lens, proof stats, case studies, systems explorer, experience, capabilities, contact
- `resume.html` — print-optimized résumé source (noindex). Regenerate `assets/Mike-Lynch-Resume.pdf` from it after edits
- `assets/css/styles.css` — design tokens (dark/light), components, motion
- `assets/js/main.js` — theme toggle (view-transition reveal), role lens (`?lens=seo|ecom|ai`), compare sliders, Gatti's architecture tabs, workflow explorer data (`WF` object), case-file drawers
- `assets/img/work/` — live-site screenshots (1200×750 WebP)

## Updating numbers
Search Console figures were pulled Oct 25, 2026. When refreshing, update the proof cards, case chips, drawer tables, résumé, and `og.png` together.

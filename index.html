    Case file · 01

    TFW Electric: the diagnosis

    What Search Console showed

    The live privacy-policy URL was flagged as noindex, but the Figma Make source had no noindex anywhere. Two causes: an older deployment was still being served, and a React SEO component was rewriting robots metadata after the page loaded. Google indexes from the initial HTML, so the JavaScript change came too late.

    The fix, in order

    1. Moved robots and canonical tags into the static index.html head and confirmed them in the raw HTML response, not the rendered page.
    2. Consolidated on one canonical host so Google stopped splitting signals between www and non-www.
    3. Shipped robots.txt and a real XML sitemap covering every route.
    4. Added Electrician / LocalBusiness schema: Georgia Class II license, owner, phone, 20+ years, and services (panel upgrades, EV chargers, generator transfer switches, rewiring, surge protection).
    5. Wrote county-level service copy for the way people actually search for an electrician in Gwinnett.
    6. Submitted the sitemap and requested indexing for the core pages.

    Case file · 02

    Gatti’s Garage: the migration rules

    Why it’s more than a CSV upload

    A migration fails quietly. Duplicated orders, customers getting surprise receipt emails, or historical lines linked to the wrong product are all easy to miss. So the pipeline runs on rules, not guesswork:

    • Keep order identity: existing history uses a #bcgg- prefix, and Matrixify matches exact order names, so dropping the prefix would create duplicates.
    • Import quietly: receipts and staff notifications off, inventory bypassed, malformed phone numbers blanked, partial shipments held for manual review.
    • Link products conservatively: products are linked only on a confident SKU or handle match. Anything uncertain becomes a tagged custom item.
    • Customers before orders: 258 missing customers are imported first so historical orders attach to real customer records.
    • Reject bad inputs: a two-byte blank export was caught and blocked before it could touch Shopify.

On the brand site, the “Built to Be Ridden” editorial feature turns a vendor article into rider-first content, with sponsored links marked rel="sponsored nofollow".

    Case file · 03

    Childcare: the enrollment playbook

    The repeatable pattern

    1. Find the gap in Search Console. High impressions with almost no clicks means a page is close to ranking but losing on relevance or CTR.
    2. Own the questions competitors skip. Free VPK eligibility, application steps, and after-school pickup at specific elementary schools.
    3. Make trust visible. Ratios, licensing, safety practices, director names, and real classroom photos replacing AI placeholders.
    4. Get every lead into one tracked form. Same form everywhere, hidden attribution fields, and GA4 events that fire once per action.
    5. Report honestly. Compare equal periods and separate branded from non-branded traffic. A baseline is not a growth claim.
